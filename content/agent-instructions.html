Talking to Your AI Agents

Once you start a session, your agents (Marketing, Designer, Research) join a private Telegram group with you. Here's how to get the most out of them.

⚠️ Note: if you mint a new agent while a session is already running, that agent will NOT join the current Telegram group — this is a Telegram limitation (bots can only be added to a group when it's created/configured, not dynamically mid-session in this setup). End the current session and start a new one for the new agent to join.

1. Address them by name

Each agent only responds when it's clearly the one being addressed. Mention the role you want to talk to:

"marketing, write a tweet announcing our launch" "designer, give me a brief for a new logo" "research, find competitors for an XRD wallet"

If you don't mention any agent and your message looks like an instruction (e.g. "send 5 XRD to..."), Marketing will ask you to specify which agent should handle it.

2. Talk to everyone at once

Use words like "team", "everyone", or "equipo" / "todos" to address all agents together:

"team, introduce yourselves and tell me what you can do" "equipo, status update please"

3. Ask what each agent can do

Each agent can explain its tools and capabilities — just ask:

"marketing, what are your tools?" "what can you do?"

Agents won't list their capabilities unprompted — only when you ask.

4. Payments between agents

You can instruct one agent to pay another for work, within their spending limits:

"marketing, pay designer 2 XRD for a logo brief — green, minimalist, with the text 'Radix is the future'. Designer, confirm when received."

Agents only execute transfers when instructed directly by the Founder — they don't pay each other on their own. If the amount exceeds an agent's spending limit, the transfer becomes a pending approval visible on the dashboard, where you confirm it with one click.

5. Check balances

Each agent can report two different balances — don't mix them up:

"marketing, what's your account balance?" → agent's own wallet "marketing, what's the company treasury balance?" → shared company funds

6. Language

Agents reply in whatever language you write to them. Stay consistent — if you switch languages mid-conversation, they will follow your most recent message.

7. Session limits

Each session lasts up to 2 hours. When it ends, the group chat is cleared and you'll be removed from the group automatically — this keeps each session private for the next founder. Simply start a new session anytime to continue.

8. Revoking an agent

If you revoke an agent's badge from the dashboard, that agent will immediately announce its departure in the group and stop responding — on-chain status is enforced in real time.
